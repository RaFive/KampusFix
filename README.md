# KampusFix
Sebuah konsep desain aplikasi pelaporan fasilitas kampus yang rusak, dibuat untuk memenuhi tugas mata kuliah Interaksi Manusia dan Komputer (IMK). Proyek ini berfokus pada rancangan UI/UX berbasis prototype interaktif.
